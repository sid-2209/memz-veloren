## State Machine Diagram

```
┌─────────────────────────────────────────────────────────────────┐
│              Voice Dialogue State Machine                       │
└─────────────────────────────────────────────────────────────────┘

                    ┌──────────┐
                    │   IDLE   │ ◀─────────────────┐
                    └────┬─────┘                   │
                         │                         │
                         │ Player presses V        │
                         │ (near NPC)              │
                         ▼                         │
                  ┌──────────────┐                 │
                  │  RECORDING   │                 │
                  │              │                 │
                  │ 🎤 Listening │                 │
                  └──────┬───────┘                 │
                         │                         │
                         │ Player releases V       │
                         ▼                         │
                ┌─────────────────┐                │
                │ TRANSCRIBING    │                │
                │                 │                │
                │ ⏳ Processing   │                │
                └────────┬────────┘                │
                         │                         │
                         │ STT complete            │
                         ▼                         │
              ┌───────────────────────┐            │
              │ CONTEXT_RETRIEVAL     │            │
              │                       │            │
              │ 🔍 Fetching memories  │            │
              └──────────┬────────────┘            │
                         │                         │
                         │ Context ready           │
                         ▼                         │
                ┌─────────────────┐                │
                │   THINKING      │                │
                │                 │                │
                │ 🤔 Generating   │                │
                └────────┬────────┘                │
                         │                         │
                         │ LLM complete            │
                         ▼                         │
              ┌───────────────────────┐            │
              │   SYNTHESIZING        │            │
              │                       │            │
              │ 🎵 Creating voice     │            │
              └──────────┬────────────┘            │
                         │                         │
                         │ TTS complete            │
                         ▼                         │
                ┌─────────────────┐                │
                │   SPEAKING      │                │
                │                 │                │
                │ 🗣️ Playing audio│                │
                └────────┬────────┘                │
                         │                         │
                         │ Audio finished          │
                         │ OR                      │
                         │ Player interrupts       │
                         │ OR                      │
                         │ Player walks away       │
                         │                         │
                         └─────────────────────────┘

State Transitions:
  IDLE → RECORDING: Player presses V near NPC
  RECORDING → TRANSCRIBING: Player releases V
  TRANSCRIBING → CONTEXT_RETRIEVAL: STT complete
  CONTEXT_RETRIEVAL → THINKING: Context ready
  THINKING → SYNTHESIZING: LLM response ready
  SYNTHESIZING → SPEAKING: TTS audio ready
  SPEAKING → IDLE: Audio finished / interrupted / timeout

Error Handling:
  Any state → IDLE: On error (show error message)
  SPEAKING → RECORDING: On interruption (full-duplex)
```
